Koffan est une webapp légère pour gérer des liste de courses, conçue pour les couples et les familles. Elle permet la synchronisation en temps réel sur plusieurs appareils, pour que tout monde sache ce qu'il faut acheter et ce qui est déjà dans le panier.

L'application marche sur n'importe quel navigateur sur téléphone et ordinateur. Un seul mot de passe - pas d'inscription compliquée requise.
